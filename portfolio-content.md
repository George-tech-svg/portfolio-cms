### HR Workforce Analytics & Attrition Prediction

**Category:** Data Analytics & Business Intelligence

**Card description:** Combining Power BI dashboards and predictive modeling to explore employee attrition and communicate workforce patterns.

**Project description:** I analyzed the IBM HR Analytics sample dataset to explore differences across departments, job roles, overtime, and other workforce characteristics. The project brings together interactive reporting, predictive models, and documented recommendations for discussing retention risks. It demonstrates how analytical work can be presented in a format that supports business conversations.

**Tools:** Python, pandas, scikit-learn, XGBoost, Power BI, DAX, Power Query.

**Repository:** https://github.com/George-tech-svg/-HR-Workforce-Analytics-Attrition-Prediction

### Business Intelligence Data Pipeline

**Category:** Data Engineering & Automation

**Card description:** Connecting web data collection, transformation, warehouse storage, modeling, and interactive reporting in one project.

**Project description:** I developed a workflow for collecting book data, cleaning and transforming it, and organizing it in a MySQL data warehouse. The project connects these stages with modeling, dashboard reporting, exports, and orchestration components. It demonstrates how raw records can move through a structured workflow into an interface that people can explore.

**Tools:** Python, MySQL, ETL, web scraping, Streamlit.

**Repository:** https://github.com/George-tech-svg/business-intelligence-platform

### SMS Spam Classification

**Category:** Machine Learning

**Card description:** An interactive text classification application that identifies likely spam messages using natural language processing and machine learning.

**Project description:** I explored the SMS Spam Collection dataset, prepared text features, and compared classification models. The final approach uses TF-IDF features and a support vector machine, with a Streamlit interface for individual and batch predictions. This project connects data exploration, feature preparation, model evaluation, and application development. Its scope is English-language SMS classification using a historical dataset.

**Tools:** Python, pandas, scikit-learn, NLTK, TF-IDF, Streamlit.

**Repository:** https://github.com/George-tech-svg/sms_spam_detector_classifier

### Portfolio Content Management Application

**Category:** Web Applications

**Card description:** A responsive portfolio application with an owner dashboard for managing profile content, projects, certifications, media, and visitor inquiries.

**Project description:** I am developing this portfolio as a content management application. It includes an authenticated owner workspace, PostgreSQL-backed content, Cloudinary media uploads, project search, certificate viewing, and visitor communication. The interface adapts to desktop and phone screens, with expandable descriptions and a certificate browser on phones. The project brings together interface design, APIs, authentication, persistent data, and deployment configuration.

**Tools:** HTML, CSS, JavaScript, Node.js, Express, PostgreSQL, Cloudinary.

**Status:** In development.
